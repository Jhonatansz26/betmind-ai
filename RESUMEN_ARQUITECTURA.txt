1. VISIÓN GENERAL DEL PRODUCTO
================================================================================

BetMind AI es una plataforma web y aplicación móvil SaaS para analítica 
avanzada de apuestas deportivas basada en ciencia de datos y aprendizaje 
automático.

**Diferencial Clave:** El sistema NO predice favoritos guiándose por cuotas 
bajas. Calcula la probabilidad real del evento evaluando tendencias 
cuantitativas y cualitativas para encontrar apuestas con Valor Esperado 
Positivo (+EV).

**Regla Estricta de 90 Minutos:** Todos los análisis y modelos estadísticos 
consideran exclusivamente el tiempo reglamentario de 90 minutos (excluyendo 
prórrogas/tiempos extra).

**Ligas Objetivo Iniciales:**
- Liga BetPlay (Colombia) - ID: 239
- Premier League (Inglaterra) - ID: 39
- LaLiga (España) - ID: 140

- Clean Architecture Enterprise (7 capas)

- Dependency Injection

5. FLUJO COMPLETO DE DATOS (FASE 4)
================================================================================

Cliente API
    │
    ▼
GET /api/v1/predictions/{match_id}
    │
    ▼
PredictionOrchestrator.get_prediction()
    │
    ├─► 1. CacheService.get() → HIT/MISS
    │
    ├─► 2. MatchRepository.get_by_id() → Match ORM
    │
    ├─► 3. TacticalAnalysisRepository.get_by_match_id()
    │       │
    │       ├─► Si existe y < 6h: USAR CACHÉ
    │       │   └─► _convert_orm_to_pydantic()
    │       │   └─► _run_quantitative_analysis() (solo Fase 3)
    │       │   └─► Tiempo total: <1s
    │       │
    │       └─► Si no existe o > 6h: EJECUTAR PIPELINE
    │           └─► run_full_analysis() (Fase 3 + Fase 4)
    │           └─► _persist_tactical_analysis()
    │           └─► Tiempo total: ~21s
    │
    ├─► 4. _build_response() → PredictionResponse
    │
    └─► 5. CacheService.set() → Persistir en caché

Pipeline ML:
    ┌─────────────────────────────────────────────────────────────┐
    │  run_full_analysis()                                        │
    │    ├─► Fase 3: Motor Cuantitativo (Poisson) - sincrónico   │
    │    │   ├─► calculate_league_averages()                      │
    │    │   ├─► calculate_team_strength() × 2                    │
    │    │   ├─► calculate_lambdas()                              │
    │    │   ├─► build_score_matrix()                             │
    │    │   ├─► build_all_markets()                              │
    │    │   └─► enrich_markets_batch()                           │
    │    │                                                        │
    │    └─► Fase 4: Cerebro Táctico (Groq Llama 3.3) - async    │
    │        ├─► NarrativeOrchestrator                            │
    │        │   ├─► asyncio.gather (paralelo):                   │
    │        │   │   ├─► generate_goals_narrative()               │
    │        │   │   ├─► generate_cards_narrative()               │
    │        │   │   └─► generate_corners_narrative()             │
    │        │   └─► generate_bet_builder() (secuencial)          │

6. MODELOS CLAVE
================================================================================

**MatchPredictionOutput (Fase 3):**
- match_id, model_version
- lambda_home, lambda_away (xG)
- markets: list[MarketProbability]
- score_matrix: ScoreMatrix
- confidence_score (0-100)

**TacticalAnalysis (Fase 4):**
- match_id, model_version
- goals_narrative: MarketNarrative
- cards_narrative: MarketNarrative
- corners_narrative: MarketNarrative
- bet_builder_suggestions: list[BetBuilderCombination]
- overall_confidence (0-100)
- match_preview_headline
- llm_model_used, data_completeness_score

**MarketNarrative:**
- market_name, our_probability
- recommendation
- pros: list[ProConPoint] (2-5)
- cons: list[ProConPoint] (1-4)
- signal_strength (STRONG/MODERATE/WEAK)
- key_risk, tactical_summary
